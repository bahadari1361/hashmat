ERP ohne Schnittstelle an Microsoft 365 anbinden

Eine Branchen-ERP-Software ohne offene API sollte Daten an Microsoft 365 liefern. Statt vorschnell zuzusagen, habe ich ein Testprotokoll für die Entscheidung entwickelt.

Ausgangslage

Viele Daten lagen in einer Desktop-ERP-Software für das Handwerk, die keine offene Schnittstelle bietet. Die Frage war, ob Desktop-Automatisierung eine tragfähige Brücke sein kann.

Vorgehen

  1. Optionen prüfenExport-Funktionen, Datenbankzugriff und Oberflächen-Automatisierung mit Power Automate Desktop gegeneinander abgewogen.
  2. TestprotokollKonkrete Kriterien vor einer Zusage an die Geschäftsführung: Stabilität bei Oberflächenänderungen, Fehlerbehandlung, Laufzeit und Pflegeaufwand.
  3. EmpfehlungKlare Entscheidungsgrundlage statt eines Versprechens, das im Betrieb nicht hält.

Ergebnis

  • Realistische Einschätzung von Aufwand und Risiko
  • Messbare Kriterien für die Entscheidung der Geschäftsführung

Technische Details

RPA auf Desktop-Oberflächen ist anfällig für Updates und Bildschirmänderungen. Deshalb gehört ein Testlauf mit echten Daten vor jede Zusage.
