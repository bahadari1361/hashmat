Automatische Wartungserinnerungen für rund 1.600 Kunden

Aus zwei Excel-Dateien wurde eine saubere Anlagenliste in SharePoint – und daraus eine dreistufige E-Mail-Serie, die Wartungstermine automatisch anstößt.

Ausgangslage

Wartungserinnerungen wurden bisher manuell verschickt. Die Kundendaten lagen in zwei getrennten Excel-Dateien, mit mehreren Anlagen pro Zeile und uneinheitlichen Namensfeldern.

Vorgehen

  1. Daten zusammenführenBeide Dateien mit Power Query zusammengeführt (Abfragen anfügen) und auf eine Zeile pro Anlage aufgeteilt, sortiert nach Kundennummer.
  2. Daten bereinigenNamen in Vor- und Nachnamen getrennt, als formatierte Tabelle angelegt. Ein falscher „über 5.000 Zeilen“-Fehler beim Import ließ sich auf Geisterzeilen zurückführen und beheben.
  3. SharePoint als DatenbasisJede Zeile der SharePoint-Liste steht für eine Anlage eines Kunden, mit Status-Spalte für den Fortschritt der Erinnerung.
  4. E-Mail-Serie bauenMehrere Flows versenden eine dreistufige Serie. OData-Filter auf die Status-Spalte steuern, wer welche E-Mail erhält; Fristen werden mit addDays berechnet.
  5. GestaltungTabellenbasiertes HTML im Firmendesign, damit die Mails auch in Outlook korrekt aussehen, mit dynamischen Inhalten aus Compose-Schritten.

Ergebnis

  • Erinnerungen gehen termingerecht raus, ohne Serienbrief und Handarbeit
  • Für jede Anlage ist sichtbar, welche Stufe erreicht ist
  • Die Datenbasis ist erstmals sauber und in einer Liste

Technische Details

Auswahlspalten erfordern in Ausdrücken das Suffix .Value bzw. im OData-Filter Status/Value eq '…'. Das ist eine häufige Fehlerquelle bei Power Automate mit SharePoint.
