Datenbereinigung und Migration

Aus verstreuten, uneinheitlichen Tabellen wird eine saubere Datenbasis für Apps und Automatisierung.

Typische Ausgangslage

Stammdaten liegen in mehreren Excel-Dateien mit unterschiedlichen Spalten, Dubletten und mehreren Werten pro Zelle. Darauf lässt sich nichts automatisieren.

Lösung

  1. ZusammenführenQuellen mit Power Query anfügen und auf ein einheitliches Schema bringen.
  2. Aufteilen und typisierenMehrfachwerte in eigene Zeilen, Namen und Adressen in eigene Spalten.
  3. PrüfenDubletten entfernen, Pflichtfelder prüfen, Geisterzeilen beseitigen.
  4. MigrierenImport als formatierte Tabelle in eine SharePoint-Liste mit passenden Spaltentypen.

Nutzen

  • Eine verlässliche Datenquelle
  • Grundlage für Apps, Flows und Berichte
  • Wiederholbar, wenn neue Daten kommen

Technik im Detail

Power Query (Abfragen anfügen, Spalte nach Trennzeichen teilen, Datentypen), Prüfung des tatsächlich letzten Zellbereichs, Import über „Liste aus Excel“.
