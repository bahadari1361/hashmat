Microsoft Cloud

Microsoft 365 and Azure – set up securely

Introducing Microsoft 365 with structure, securing identities and running the tenant properly.

Many companies already have Microsoft 365 but rarely use and secure it consistently. I bring a clear structure, secure sign-in and settings that fit the size of your business.

What I take care of

  • Setting up and administering Microsoft 365 tenants
  • Entra ID: MFA, Conditional Access policies, groups and roles
  • Structure for Teams, SharePoint and OneDrive
  • Exchange Online: mailboxes, shared mailboxes, forwarding reviews
  • Security reviews: sign-in logs, suspicious accounts, external sharing
  • Azure fundamentals and resource hardening

Your outcome

  • A tenant whose structure you understand
  • A much smaller attack surface
  • Clear ownership of data and access
