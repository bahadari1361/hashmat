Automation

Process automation with the Microsoft Power Platform

Automating recurring work – traceable, maintainable and built on the licences you already have.

Spreadsheets, forwarded emails and reminders kept in someone’s head work until someone is away. I model your processes, automate the repetitive steps and leave decisions where they belong: with your team.

What I take care of

  • Process discovery and modelling in BPMN
  • Cloud flows for approvals, notifications and data sync
  • Power Apps as a simple interface for lists and tasks
  • Connecting external services via REST APIs
  • Desktop automation (RPA) for software without an API
  • Data cleansing with Power Query before any automation

Your outcome

  • Less manual work, fewer errors
  • Every step is logged
  • Documentation your team can maintain

Technologies

  • Power Automate Desktop
  • Power Apps
  • Microsoft Forms
  • Power Query
  • REST-API
