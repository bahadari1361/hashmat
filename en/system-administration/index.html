System administration and IT security for daily operations

Day-to-day IT operations, user management, networking and IT security – reliable and documented.

Good administration goes unnoticed: sign-in works, the backup is there, the printer prints. I take care of this everyday work while keeping security in view – with experience from an environment of more than 2,500 users across 34 sites.
