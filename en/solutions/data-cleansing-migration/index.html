Data

Data cleansing and migration

Scattered, inconsistent spreadsheets become a clean data foundation for apps and automation.

Typical situation

Master data sits in several Excel files with different columns, duplicates and multiple values per cell. Nothing can be automated on top of that.

Solution

  1. MergeAppend sources with Power Query and align them to one schema.
  2. Split and typeMultiple values into separate rows, names and addresses into separate columns.
  3. ValidateRemove duplicates, check required fields, clear ghost rows.
  4. MigrateImport as a formatted table into a SharePoint list with suitable column types.

Benefits

  • One reliable data source
  • Foundation for apps, flows and reports
  • Repeatable when new data arrives

Technical detail

Power Query (append queries, split column by delimiter, data types), checking the true last used range, import via “List from Excel”.
