Intranet

Role-based intranet and knowledge base

A SharePoint intranet with portals per role, digital requests and embedded apps.

Typical situation

Instructions, forms and contacts are scattered. New staff depend on asking around, and nobody knows which version is current.

Solution

  1. Roles, not foldersA home page as hub and separate portals for field service, administration, management and all staff.
  2. ContentProcedures, safety, first aid, contacts and templates in one place.
  3. Digital processesReports and requests via Microsoft Forms with approval in Power Automate.
  4. AppsPower Apps where lists aren’t enough – for tasks or a contact directory, for example.

Benefits

  • One entry point for every employee
  • Current content instead of file versions
  • Permissions managed centrally through groups

Technical detail

Hub site with associated portal sites, audience targeting via Entra ID groups, embedded Power Apps, forms with approval flows.
