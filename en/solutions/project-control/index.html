Automation

Project control with phases and checklists

A project board where every card knows its next step – and phases can only change once the checklist is complete.

Typical situation

Projects run on lists, emails and memory. Often only one person knows what’s next, and steps get skipped when things are busy.

Solution

  1. Phase modelThe path from order to completion is split into clear phases, each with its own checklist.
  2. Automatic card titleThe title shows owner, project number and the next open step – updated automatically.
  3. Phase gateIf a card is moved too early, the flow moves it back and lists the open items as a comment.
  4. IntegrationThe board runs as a tab in Microsoft Teams; projects are created from Excel via API.

Benefits

  • Everyone sees their projects with the next step
  • No phase change without completed tasks
  • Full project history is retained

Technical detail

Checklist templates as JSON inside the flow, creation via HTTP action against the board’s REST API, trigger on card movement, daily sync with the project list.
