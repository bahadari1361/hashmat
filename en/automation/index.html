Process automation with the Microsoft Power Platform

Automating recurring work with Power Automate, Power Apps and APIs – from spreadsheet to dependable process.

Many businesses run on spreadsheets, forwarded emails and reminders kept in someone’s head. That works until someone is off sick or the list gets too long. I turn this into processes that run on their own, stay traceable and make sense to your team.

What I take care of

  • Power Automate cloud flows: approvals, notifications, data sync between Excel, SharePoint, Outlook and Teams
  • Connecting external services via REST APIs, for example Trello for project control
  • Power Apps as a front end for teams who don’t want to work in raw lists
  • Desktop automation (RPA) for software without an API – after an honest feasibility test
  • Cleaning and merging data with Power Query before anything is automated
  • Branded HTML emails for customer communication that render properly in Outlook

Tools & platforms

  • Power Automate
  • Power Automate Desktop
  • Power Apps
  • Microsoft Forms
  • Excel & Power Query
  • REST APIs (e.g. Trello)

Relevant certifications

  • AZ-900

What you get

  • Less manual work and fewer forgotten tasks
  • Every step is logged and traceable
  • Documentation that lets your team maintain the flows themselves
